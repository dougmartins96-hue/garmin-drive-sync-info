Política de privacidade

Atualizada em 16 de novembro de 2026. Esta política descreve uma integração pessoal administrada pelo titular da conta GitHub dougmartins96-hue.

Dados utilizados e finalidade

A integração utiliza credenciais Garmin, tokens de autorização Google, identificadores de atividades e arquivos FIT de corrida para criar um backup privado e evitar duplicatas. FITs podem incluir data, duração, distância, frequência cardíaca, localização e outros dados registrados pelo dispositivo.

Processamento e armazenamento

As credenciais de execução são guardadas em GitHub Actions Secrets e usadas no runner durante a sincronização. Elas não são incluídas no código-fonte. Os FITs são copiados para uma pasta privada no Google Drive do titular. Garmin, GitHub e Google participam das funções de autenticação, execução e armazenamento. O operador não vende esses dados nem os utiliza para publicidade.

O aplicativo solicita apenas o escopo Google drive.file, limitado aos arquivos autorizados ao aplicativo. Esse escopo permite gerenciar esses arquivos; o código do sincronizador utiliza consulta e criação, sem chamadas de exclusão.

Controle e retenção

O titular controla o acesso ao repositório e à pasta. Pode interromper as execuções no GitHub, remover ou substituir os Secrets, revogar a conexão na Conta Google e excluir seus backups no Drive. Os arquivos permanecem no Drive até o titular removê-los. Os Secrets permanecem no GitHub até serem removidos ou substituídos. Logs seguem as configurações de retenção do GitHub; credenciais não devem ser impressas nos logs.

Análise de treinos

A análise no ChatGPT é uma etapa separada, solicitada pelo usuário e sujeita às configurações e políticas do ChatGPT e de suas conexões. Esta página pública não recebe nem apresenta os dados dessa análise.

Esta página pública

A página não contém formulários, publicidade, scripts de análise ou acesso ao Drive. Não publica atividades, mapas, rotas ou credenciais. A hospedagem pode registrar acessos técnicos conforme sua própria política. Nenhuma medida de segurança elimina totalmente o risco de acesso indevido.

Contato

O contato do operador é seu perfil público no GitHub. Não publique credenciais, dados de saúde ou localização em mensagens ou issues públicas.
